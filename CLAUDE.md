# CLAUDE.md

Голосовая викторина по Minecraft на русском языке. Задеплоена на GitHub Pages:
https://eternited.github.io/minecraft-quiz/

## Архитектура

- **Всё приложение — один файл `index.html`**: React 18 (UMD с unpkg CDN) + Babel standalone,
  JSX транспилируется прямо в браузере. Сборки, package.json и зависимостей нет.
- `minecraft-quiz.jsx` — исходный прототип из Claude-артефакта (первый коммит).
  В рантайме не используется, оставлен как референс.
- Стили — JS-объекты (inline styles) внутри index.html, пиксельная Minecraft-эстетика.
- Экраны — конечный автомат на `useState("screen")`:
  `start` → `playing` → `evaluating` → `result` → (цикл до 10 вопросов) → `final`.

## AI-интеграция (DeepSeek)

- Endpoint: `https://api.deepseek.com/chat/completions`, модель `deepseek-chat`,
  OpenAI-совместимый формат (system+user messages, `Authorization: Bearer <key>`).
- Функция называется `callClaude` — историческое имя, до коммита `97b41f8` API был Anthropic.
- **Генерация вопросов**: промпт требует строгий JSON
  `{"question","correct_answer","difficulty":"easy|medium|hard"}`; в user-промпт
  передаётся список уже заданных вопросов, чтобы избежать повторов.
- **Оценка ответов**: судья возвращает JSON `{"score":1..5,"comment","correct_answer"}`;
  score клампится в 1..5.
- `parseJSON()` срезает markdown-фенсы ```` ```json ```` перед `JSON.parse`.
- **API-ключ** вводится на стартовом экране, проверяется тестовым вызовом при сохранении,
  хранится в `localStorage` под ключом `mc_quiz_api_key`. Никуда кроме DeepSeek не уходит.

## Fallback без API

- При любой ошибке генерации — встроенный банк `FALLBACK_QUESTIONS` (15 вопросов,
  циклический индекс `fallbackIdx`).
- При ошибке оценки — локальное сравнение по ключевым словам
  (нормализация → точное совпадение = 5, все слова = 4, часть слов = 3, иначе 1).

## Голосовой ввод

- Web Speech API (`SpeechRecognition`/`webkitSpeechRecognition`), язык `ru-RU`,
  push-to-talk (зажать кнопку: touch + mouse события).
- Транскрипт прогоняется через `MC_CORRECTIONS` — таблицу regex-замен фонетических
  искажений Minecraft-терминов русским ASR («ридстон» → «редстоун» и т.п.).
- Если API распознавания недоступен (Firefox и др.) — остаётся текстовое поле,
  оно показывается всегда.

## Правила работы

- **Основная ветка — `master`**, GitHub Pages деплоится из неё (корень репозитория).
  Пуш в master = мгновенный деплой, CI и тестов нет — проверяй изменения внимательно.
- **Изменения доводить до master без участия пользователя**: если прямой push в master
  недоступен, создать PR и сразу самостоятельно смерджить его
  (`gh pr merge --merge --delete-branch`; в средах без `gh` — через GitHub MCP/API).
- **В конце каждой сессии обновлять `DEVLOG.md`** (дата — что сделано).

## Известные ограничения

- API-ключ лежит в localStorage в открытом виде и отправляется из браузера —
  осознанный компромисс для статического хостинга без бэкенда.
- Нет таймаутов/AbortController на fetch: зависший запрос = вечный лоадер.
- Приложение ориентировано на мобильный Chrome/Android (голосовой ввод);
  тестировать в первую очередь там.
