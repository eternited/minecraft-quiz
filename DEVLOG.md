## 2026-07-18 — 2026-07-18.2: standalone-режим для старых iOS (iPhone 7)

Жалоба: на iPhone 7 ярлык с экрана «Домой» открывался в Safari с адресной
строкой, на iPhone 12 Pro — как полноценное приложение. Причина: у приложения
не было ни manifest.json, ни apple-меты. Новые iOS (26+) открывают любой
«Домой»-ярлык как веб-приложение по умолчанию, а iPhone 7 навсегда на iOS 15,
где standalone требует явной декларации.

- Добавлены `manifest.json` (display: standalone, относительные start_url/scope,
  theme/background #1a1a2e) и легаси-мета Apple (apple-mobile-web-app-capable,
  status-bar-style black, title) + `theme-color`.
- Иконки: пиксельная морда крипера, `icon-180.png` (apple-touch-icon),
  `icon-192/512.png` (manifest, 512 — maskable). Генератор —
  `tests/gen-icons.js` (`npm run gen-icons`, рендер системным Chromium).
- Юнит-тесты: валидность manifest (standalone, относительные пути, реальные
  размеры PNG по IHDR), наличие всех тегов в index.html; mime .json/.png
  в тестовом сервере.
- На iPhone 7 после выкладки ярлык нужно удалить и добавить заново —
  iOS фиксирует режим открытия в момент добавления.

## 2026-07-18 — v1.7.0: актуальная локализация и вопросы с несколькими верными ответами

Кейс со скрина: «какой предмет нужен для крафта чародейского стола» —
устаревшее название («чародейский стол» → «стол зачарований») и вопрос,
у которого три равноправных верных ответа (книга, алмазы, обсидиан),
но эталоном была назначена только «Книга».

- Промпт генерации: только актуальная официальная локализация последней
  версии с анти-примерами (стол зачарований, НЕ «чародейский стол»; незерак,
  НЕ «адский камень»); при нескольких верных ответах — переформулировать
  до однозначности либо перечислить каждый в acceptable_answers.
- Факт-чекер: новые пункты проверки (актуальность названий, равноправные
  ответы) и право переписывать формулировку вопроса — `corrected_question`
  в вердикте; e2e проверяет, что исправленная формулировка доходит до экрана.
- Судья: «игрок назвал ЛЮБОЙ из равноправных верных ответов — ставь 5».
- `MC_SYNONYMS` пополнен группой «стол зачарований ↔ чародейский стол ↔
  зачаровательный стол» — даже если старое название проскочит в эталон,
  локальная страховка зачтёт ответ.

## 2026-07-18 — v1.6.0: «незерак = адский камень» — словарь синонимов и страховка оценки

Кейс из жалобы: вопрос про Нижний мир, эталон «Адский камень», игрок ответил
«незерак» — это **тот же блок** (незерак — новое официальное название,
адский камень — старое), но судья поставил 1/5.

- Введён словарь `MC_SYNONYMS`: группы «официальное / старое / разговорное»
  название одного объекта (незерак↔адский камень↔камень Нижнего мира,
  камень Края↔эндерняк, иссушитель↔визер, Нижний мир↔незер↔ад, око Края↔глаз
  эндера и др.). Локальный скоринг расширяет эталоны этими группами.
- **Страховка от несправедливого судьи**: итог = `mergeEvaluations` — лучшая
  из оценок AI-судьи и локальной проверки. Если судья занизил, а локальная
  проверка видит совпадение (точное, по стемам или через синонимы) — берётся
  высокая. Детерминированная гарантия кода, не промпта.
- Тесты: юнит на кейс «незерак/адский камень» в обе стороны, синонимы через
  acceptable_answers, отсутствие ложных склеек; e2e — мок-судья намеренно
  ставит 1 за ответ из acceptable_answers, приложение поднимает до 5,
  и поднятая оценка попадает в сумму очков.

## 2026-07-18 — v1.5.0: факт-чек вопросов, бейдж версии в потоке

По скриншотам с iPhone:

- **Кнопки наползали на номер версии**: fixed-бейдж не резервировал место,
  и прижатая к низу «ОТВЕТИТЬ» рисовалась поверх него. Бейдж теперь обычный
  элемент в конце флекс-колонки — перекрытие невозможно по построению.
  E2E-регрессия: бейдж не пересекается с «НАЧАТЬ ИГРУ» и «ОТВЕТИТЬ».
- **Некорректные вопросы/ответы** (кейс: «коренной блок острова в Крае» с
  «правильным ответом» «адский камень» — блоком Нижнего мира; по Minecraft Wiki
  остров Края состоит из камня Края/эндерняка, а незерак/адский камень — Нижний
  мир). Введён **факт-чек**: каждый AI-вопрос проверяется вторым вызовом
  с temperature 0 — ok/fix/reject; fix заменяет неверный ответ, reject ведёт
  к одной перегенерации с причиной, дальше fallback. Проверяющий дополняет
  acceptable_answers старыми и разговорными названиями (незерак ↔ адский
  камень, камень Края ↔ эндерняк). Промпт генерации явно запрещает смешивать
  измерения; судья получил право исправлять неверный эталон, если игрок
  фактически прав. Латентность второго вызова скрыта префетчем.

## 2026-07-18 — v1.3.1: бейдж версии в safe-area, судья прощает окончания

По скриншотам с iPhone 12 Pro:

- **Бейдж версии вылезал за край экрана**: `bottom/right` без учёта safe-area
  попадал в зону скругления дисплея и home-индикатора. Теперь бейдж внизу
  по центру, отступ `calc(8px + env(safe-area-inset-bottom))` с каскадным
  фолбэком (CSS-класс `.version-tag`), в мету добавлен `viewport-fit=cover`.
  E2E гоняется на вьюпорте iPhone 12 Pro (390×844) и проверяет, что бейдж
  вписан в экран и нет горизонтального overflow.
- **Ответ «Шёлковое касание» не был засчитан полностью**: ASR распознал
  «Шелков*ая* касание», судья снизил до 4/5 («в следующий раз точнее»).
  Причина: шкала «4 = по сути верно, но неточно» перевешивала общую просьбу
  прощать огрехи распознавания. Теперь и системный промпт судьи, и шкала
  явно требуют: расхождение только в окончаниях/роде/падеже/ё/регистре —
  полное совпадение, 5 баллов. Локальный fallback-скоринг аналогично:
  пословное совпадение по стемам без лишних слов = 5 (тест на кейс со скрина).

## 2026-07-18 — Качество AI-генерации, фиксы всех известных багов, тесты

Исправления (всё из списка «замечено» от 2026-07-17):

- **Найден и починен старый критический баг**: `\b` в JS-регулярках не работает
  с кириллицей — вся таблица ASR-коррекций (`MC_CORRECTIONS`) в проде никогда
  не срабатывала. Границы слов теперь строятся вручную (`[^а-яёa-z0-9]`),
  таблица вычищена (правила-пустышки и спорный «призрак»→«фантом» удалены,
  добавлен «ридстон»).
- Единый ввод ответа: голосовой транскрипт попадает в текстовое поле,
  отправляется ровно то, что видит игрок (раньше голос молча побеждал текст).
- Fallback-скоринг: числа и короткие слова больше не ломают оценку «4»
  («Минимум 10 блоков»), добавлен лёгкий стемминг для падежей, ё→е,
  числа сравниваются строго.
- Stale closures устранены: история вопросов и очередь тем в ref'ах,
  `gameIdRef` отсекает гонки старой/новой игры.
- Таймаут 15 с (AbortController) на все запросы; без ключа запросы к API
  вообще не делаются.
- `recognition.start()` обёрнут в try/catch (InvalidStateError).
- `callClaude` → `callAI`; мёртвый прототип `minecraft-quiz.jsx` удалён.

Улучшение генерации вопросов (провайдер не менялся — только промпты,
параметры запросов и логика выбора темы):

- Ротация 12 тем на стороне приложения (случайно, без повторов до исчерпания),
  тема передаётся в user-промпт.
- Новый системный промпт: Java Edition, только проверяемое по Minecraft Wiki,
  официальная русская локализация, самопроверка перед выводом,
  6 few-shot примеров; формат дополнен `acceptable_answers` (2–4 синонима).
- Температуры: 0.7 генерация, 0.2 оценка; `response_format: json_object`;
  `parseJSON` умеет вырезать JSON из окружающего текста.
- Судья получает `acceptable_answers` и засчитывает синонимы/разговорные
  формулировки; локальный скоринг тоже учитывает их (берёт максимум).
- Банк fallback-вопросов дополнен `acceptable_answers` для всех 15 вопросов.

Новые фичи (из идей прошлой сессии):

- Префетч следующего вопроса, пока игрок отвечает (латентность API скрыта;
  streaming не понадобился — префетч закрывает ту же проблему без изменения
  кода провайдера).
- Выбор сложности перед игрой (смешанная/легко/средне/сложно) — в промпт
  и в фильтр fallback-банка.
- Озвучка вопросов через SpeechSynthesis ru-RU: автоозвучка с переключателем
  (`mc_quiz_tts`) и кнопка «Прочитать вопрос».
- История результатов в `localStorage` (`mc_quiz_history`, последние 20),
  рекорд на стартовом экране и бейдж «Новый рекорд!» на финальном.

Тесты (`tests/`): 43 юнит-теста (Node VM + Babel, без рендера) и e2e
на playwright-core + системном Chromium (мок DeepSeek через route-перехват:
полный цикл с API и режим без ключа). Прогон перед пушем: `cd tests && npm test`.
Обновлён CLAUDE.md (архитектура, промпты, тесты, правила).
