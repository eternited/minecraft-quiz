# DEVLOG

Журнал разработки minecraft-quiz. Новые записи добавляются сверху.

## 2026-07-17 — Документация проекта

- Аудит текущего состояния кода (index.html, история коммитов).
- Созданы `CLAUDE.md` (описание проекта, архитектура, правила работы)
  и `DEVLOG.md` (этот файл, история восстановлена по коммитам).
- Замечено на будущее (не исправлялось, фичи не добавлялись):
  - `handleSubmitAnswer` берёт `transcript || textInput` — если сначала ответил
    голосом, а потом напечатал текст, отправится голосовой вариант.
  - В fallback-оценке фильтр `w.length > 2` внутри `every()` ломает оценку «4»
    для ответов с короткими словами/числами («Минимум 10 блоков»: «10» не проходит
    проверку длины → `every` всегда false).
  - `generateQuestion` при «Играть снова» захватывает старый `askedQuestions`
    из замыкания (stale closure) — первый вопрос новой игры получает историю
    прошлой; повторный `start()` распознавания без паузы может кинуть
    InvalidStateError (не обёрнут в try/catch).
  - Нет таймаута на fetch — при зависшем API лоадер крутится вечно.
  - Часть правил `MC_CORRECTIONS` — no-op замены самих на себя («фантом» → «фантом»),
    а «призрак» → «фантом» может исказить легитимный ответ игрока.
  - `callClaude` — устаревшее имя (API давно DeepSeek), `minecraft-quiz.jsx` —
    мёртвый файл-прототип в корне деплоя.

## 2026-04-16 — Переход с Anthropic API на DeepSeek (`97b41f8`)

- Endpoint → `https://api.deepseek.com/chat/completions`, модель → `deepseek-chat`.
- Заголовки и формат: `Authorization: Bearer`, system-сообщение в `messages`,
  ответ читается из `choices[0].message.content` (OpenAI-совместимо).
- Снята валидация префикса ключа `sk-ant-`.
